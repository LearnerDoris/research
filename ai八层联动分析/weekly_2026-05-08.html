📌 本周三个核心结论

  1. L1 内部因 OpenAI 单点风险二度发酵而开始分化。AMD 5/5 财报 EPS $1.37 / 营收 $10.25B (+38% YoY) / Q2 指引 $11.2B (+45% YoY) 三项全超，盘后 +18.6%，5/6 创历史新高 $430.60。但同日 AVGO 因 WSJ 报 OpenAI $18B 融资条款（Broadcom 要 MSFT 接 40% 才肯垫资）周四下跌 4%，从 5/5 历史高 $427.36 回落至 5/7 收 $417.21。NVDA $211.50（+1.85%）等 5/20 自家财报。L1 龙头股的需求基础正在从"OpenAI 集中"重定价到"自定义 silicon 客户分散度"。
  2. 上周报告设的"翻多触发条件"在 ANET 上首次失效，是触发条件机制的成功验证。ANET 5/5 财报营收 $2.71B 超共识 $2.62B 但低于上周设定的翻多阈值 $2.78B，叠加 Q2 指引偏保守，盘后 -13.64%。这正是上周"营收 ≥$2.78B"严格阈值的目的——超共识不等于超预期。同期 IREN 上周翻多触发条件"Sweetwater 1.4GW 上线"在 5/1 实锤兑现 + 5/5 宣布 $625M 收购 Mirantis；ORCL 减仓阈值 $161 不仅未破，反而在 4/13–5/6 间从 $155 涨至 $194（+25%），减仓判断本周需正式撤回。
  3. 宏观面双向同时松动：油价从 5/4 高点回落、Warsh 5/11 全院投票临近、5/8 NFP 共识 62k 显著低于 3 月 178k。Brent 5/4 收 $114.44（+6%），到 5/7 回落至 $100.06（-1%），美伊就开放 Hormuz 海峡谈判进入核心阶段。Warsh 4/29 委员会 13-11 党派票通过、5/11 周全院投票，鸽派降息预期可能因此延后。5/8 NFP 是 4/2 关税生效后第一份就业报告，若 ≤ 50k 将给降息预期添柴。三件事情同时松动意味着市场叙事下周可能从"AI 财报"快速切换到"宏观货币"。

🔗 跨层联动信号

强信号 A：L1 自定义芯片周期使 AVGO 与 NVDA 第一次出现"反向脱钩"
  • 5/4 触发：WSJ/路透报道 OpenAI 与 Broadcom 协议中 Broadcom 要求 MSFT 包销 40% 芯片才肯垫资 $18B 第一阶段（1.3 GW 数据中心）
  • 5/5 反应：AVGO 创历史收盘新高 $427.36，市场原本"忽略"该报道
  • 5/7 反转：AVGO 跌 4%，跌至 $417.21，同日 NVDA +1.85% 至 $211.50
  • 逻辑：当 OpenAI 单点风险被聚焦时，市场资金从"AVGO（自定义芯片高度依赖 OpenAI 包销）"流向"NVDA（GPU 客户高度分散）"。这是上周报告 L1 内部第一次出现真正的资金分流，与 4/28 那次"集体下跌"完全不同。
  • 投资含义：L1 内部不再适合用"AI 半导体"一条线统揽。AVGO 和 NVDA 在客户分散度这条主轴上正式分叉。
强信号 B：L8 capex → L4 价格的传导继续单向放大
  • 持续性证据：MU 从上周 $577.79 涨至 5/7 $678.30（+17.4%），SNDK 各源数据 $1,300-$1,410 区间继续创新高
  • 客观面：4/29 META 财报上调 2026 capex 上限至 $145B（vs 上周末 $135B），Hargreaves Lansdown 分析师 Britzman 公开归因"part of the increase came from higher memory prices"
  • 对比信号 A：L1 内部现在按"客户分散度"定价；但 L4 仍按"hyperscaler 集体 capex"定价——MU/SNDK 不存在客户集中度问题，所有 hyperscaler 都必须从他们买
  • 投资含义：L4 是过去三周里"最干净"的 AI capex 受益方。下周需关注 MU 6/29 自家财报前的 momentum 是否能维持，标普 500 头号股 SNDK 估值已 PE ~40x 进入顶部担忧区。
中信号 C：宏观面同时松动可能切换市场叙事
  • 油价：Brent 5/4 收 $114.44（+6%、四年新高）→ 5/7 收 $100.06（-1%）；WTI 同步从 $106.42 回到 $94.81。美伊就开放 Hormuz 谈判进入第 9-10 周
  • Warsh：4/29 银行委员会 13-11 党派全票通过；5/11 周全院投票；Powell 任期 5/15 结束。Warsh 鹰派立场可能延后年内降息预期
  • NFP：5/8 4 月就业数据共识 62k（GS 75k），是 4/2 关税生效后首份就业报告，若 ≤ 50k 将强化"经济快速放缓 → Fed 必须降息"叙事
  • 三方向博弈：油价回落 + 弱就业 + 鹰派 Fed 接班，叙事在"软着陆 → 必须降息 → 鹰派耽误"之间快速切换
  • 投资含义：L1 / L8 forward P/E 22-30x 高估值层在叙事切换时波动会被放大；L4（MU forward P/E ~9x）和 L5（IREN 现金流刚刚启动）相对低基期标的反而获得估值松绑
