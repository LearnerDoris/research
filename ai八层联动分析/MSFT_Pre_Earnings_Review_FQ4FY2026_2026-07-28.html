这次财报的意义：这不是一份"看当季数字"的财报，而是一次对整个 AI 投资逻辑的检验。市场已经把微软打到近十年低位的 forward P/E， 根本原因就是怀疑"史上最大的 capex 能不能赚回来"。因此本次财报真正的胜负手不是 EPS 是否小幅超预期，而是两件事：①Azure 的 constant-currency 增速能不能守住 ~40%；②公司对 FY2027 capex / free cash flow 的指引口径。 这两点决定了折价是继续扩大、还是开始回补。

02两个胜负手

① Azure 增速 —— 需求的温度计

Azure 的 constant-currency 增速是判断"capex 有没有真实需求"的最直接信号。FY2026 三个季度是 +40% / +39% / +40%，公司 Q4 指引 39–40%。市场把 ~37% 当作一条隐含警戒线：

  • ≥ 40% 或加速 → 强烈验证需求，capex 焦虑站不住脚 → 偏多
  • 37–39% → 符合，中性；看管理层对产能/需求的措辞
  • < 37% → 红旗，市场会质疑"是不是需求见顶了" → 偏空

② FY2027 capex / FCF 指引 —— 现金流拐点的时间表

比当季数字更重要的，是管理层怎么谈 FY2027 的 capex。市场想听到的不是"capex 停止增长"（不现实），而是"增速开始放缓"的信号——因为这正是 free cash flow 拐头向上的前提。

  • 利好：capex 继续增长，但明确"增速放缓"，并给出 FCF 回升的时间感 → FY2028 拐点可见
  • 利空：FY2027 capex 大幅上调，却给不出 FCF 何时改善 → "只烧钱不见回报"的叙事强化
大白话：盖厂房还得继续盖，但市场想知道"什么时候盖得没那么疯了、租金什么时候能盖过盖楼的钱"。管理层这句话的口气，比这一季度赚了多少更能决定股价。

03情景推演（财报后 1 日）

Bull · 35% · +6% ~ +12%

Azure cc 守住/加速到 ~40%；FY2027 capex 增速明确放缓、FCF 拐点可见；Copilot 席位/ARR 披露亮眼；operating margin 稳在 46%+。近十年低位的折价开始向街的水平回补。

Base · 45% · −4% ~ +6%

Q4 符合指引（$86.7–87.8B，EPS ~$4.24）；Azure ~39–40%；FY2027 capex 继续上调但用"增速放缓"措辞；毛利稳定 ~67–68%。反应取决于 capex/FCF 措辞，而非当季数字。

Bear · 20% · −8% ~ −15%

Azure cc 跌破 ~37%；FY2027 capex 大幅上调却无 FCF 时间表；毛利进一步压缩；OpenAI/竞争担忧被放大。倍数在"ROI 存疑"下继续下修。

04盯什么：财报速读清单

  • Azure cc 增速——是否 ≥ 40%？管理层是否重申"capacity tight / 供不应求"？
  • FY2027 capex 口径——增速是加速还是放缓？有没有 FCF 拐点的时间感？
  • Gross margin——是否稳住 ~67–68%，还是继续被折旧压缩？
  • Microsoft Cloud 毛利率——AI 基建效率是否改善？
  • Copilot 变现——席位数、ARR、附加率有没有实质披露？
  • Commercial bookings / RPO——远期合同（backlog）反映的需求强度
  • non-GAAP EPS——剔除 OpenAI 公允价值波动后的"真实"盈利
  • 资本回报——回购/股息节奏（9M FY26 已回馈 ~$37B）

05我们的立场

财报前：观望（不追高）

12 个月我们对微软是 BUY / 目标 $470（+21%）——理由见首次覆盖报告。但财报是一个正好押在两个胜负手上的二元催化剂，且就在约 1 天后。 按项目的 14 天催化剂纪律，加仓建议在此窗口内改为观望：不要在财报前 1 天追高。

财报后：分批建仓

更理性的做法是用财报后的波动建仓：

  • 若 Bull（Azure 守 40% + capex 放缓信号）→ 可更积极，向街的 $560+ 靠拢加仓。
  • 若 Base 回调 / Bear 超跌（数字 OK 但 capex 措辞偏鹰导致下杀）→ 正是我们更喜欢的入场区，因为下行有 DCF ~$365（≈ 现价）支撑。
  • 唯一会让我们转 Neutral：Azure cc 跌破 ~37% 而 capex 仍在加速——那意味着"需求见顶 + 只烧钱"，逻辑被证伪。
