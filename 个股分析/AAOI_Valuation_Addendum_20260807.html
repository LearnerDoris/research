为什么 30x：相对"便宜同行" Fabrinet 的 ~48x P/E 打约 35–40% 折扣，远低于 Coherent/Lumentum 的三位数倍数。折扣对应三个可验证的事实：AAOI 是 1.6T 大客户的第四供应商（订单最后进、最先出）；diluted 股本一年 +42% 且扩产仍未走完；32–33% 的毛利率目前是目标不是事实。倍数是本报告唯一的主观假设，已在模型 Valuation Summary tab 中明示。

2为什么 DCF 不能当锚——以及它仍然告诉我们的事

老老实实跑一遍 DCF（Base 路径：FY26E 收入 $1.1B → FY27E $2.57B → FY30E $4.05B，non-GAAP 营业利润率爬到 21%，capex 从 $1.6B/年退坡到 $0.4B/年，WACC 12.5%、永续增长 3%），得到的答案是 $21–37/股；把 WACC/g 全网格里最乐观的角落（10% / 4%）也只到 $73。远低于市价，不是因为"市场错了"，而是因为这个方法此刻在结构上吃亏：

  • 5 年显性期恰好覆盖了 capex 高峰（仅 Q2 单季就投了 $565.5M，call 口径），却只收获了产能释放的头两三年；
  • FY2026–27 的自由现金流为深负（模型估 -$1.6B / -$0.6B），把现值大幅拉低；
  • 市场真正定价的 FY2031+ 现金流全部被压缩在 terminal value 一个数字里。
Reverse DCF——这是本增补里最值得记住的一个数字。倒过来问：$124.22 的股价（市值 ~$9.97B）需要什么才成立？答案：在 12.5% WACC / 3% 永续增长下，需要 AAOI 从 FY2031 起每年产生约 $1.7B 的稳态 FCF——约等于 FY2030E 收入 $4.05B 的 42% FCF margin，是我们 Base 情景终值（~$0.5–0.7B）的 2.5–3 倍。换句话说：现价已经把管理层"CPO/ELSFP 时代 55–65% 毛利率"的承诺当成了基础情景。买现价的人，买的不是 800G，是 2027 年之后的 CPO 故事。这不是判断，是算术。
