一句话点评：这是一份把我们的多头逻辑全部验证、并且超出的财报。三个胜负手全部押中且更好： ① Azure 不但守住、还加速到 +43%（FY2027 指引 +45%），并首次跨过 $100B 年收入；② 需求得到硬证据——commercial RPO（已签约未确认收入）暴增 +84% 到 $678B（即便剔除 OpenAI 也 +25%）； ③ AI 变现落地——Copilot 付费席位达 3000 万（约 $10B ARR run-rate）。Q4 收入 $90.0B、non-GAAP EPS $4.74，全面超预期。 市场的反应是史上最大单日市值增幅（+15.5%），股价一周内从我们的锚定价 $389.51 冲到 $464.72，几乎一周就打到了我们 $470 的 12 个月目标价。 但——公司同时把 FY2027 capex 指引大幅上调到 $255–260B（+35%），意味着自由现金流的拐点被推后到 ~FY2029+。所以：基本面更强了，但"便宜"的重估已基本兑现，风险回报从"胖球"变得更均衡。我们维持 BUY、目标价上调到 $515，但立场转为回调再加、不要追这根史诗大阳线。

02哪个情景兑现了：冲破多头上限

我们盘前给出的三情景里，Bull（35% 概率、预期 +6~12%）押中了方向——但实际反应冲破了我们的多头上限：单日 +15.5%，创下美股史上最大单日市值增幅。

诚实复盘：BUY 对了，"财报前观望"避开了尾部风险、也错过了大阳线

两件事分开说：（1）12 个月 BUY / 目标 $470 —— 方向完全正确，而且一周就基本兑现（股价 $465 ≈ 目标 $470）。 （2）财报前"战术观望"（14 天催化剂纪律）——这条纪律的作用是避开约 20% 概率的 bear 尾部（-8~-15%），它是风险管理、不是预测。结果是：它成功规避了下行风险，但也错过了这根 +15.5% 的大阳线。 拿着我们报告的投资者本就是"BUY + 目标 $470"的持有/加仓方，而非做空方；只是在财报前一天没有去追。我们如实承认：这次"观望"在事后看错过了单日暴涨。纪律有时会让你错过运气，但它换来的是不被 20% 的坏结果击穿——这个取舍我们仍然认。

03两个胜负手怎么解决的

① Azure：不但没降速，反而加速到 +43%

这是最关键的信号。Azure 从 FY2026 的 40%/39%/40%，Q4 加速到 +43%，公司给 FY2027 的指引是 ~45% cc——对一个刚跨过 $100B 年收入的业务来说，这是极强的需求信号。管理层明确说 Azure 需求仍然超过供给（demand exceeds supply）。

② Capex：不是放缓，而是大幅加速到 $255–260B

这是好消息里的新麻烦。我们盘前的多头逻辑是"capex 增速终将放缓 → FCF 从 FY2028 拐头向上"。但公司把 FY2027 capex 指引给到 $255–260B（+35%）——capex 不是放缓，而是继续加速。逻辑没有被证伪，但时间表变了：现金流拐点从 ~FY2028 推后到 ~FY2029+。

为什么市场还大涨？因为这次 capex 的大增是被需求背书的（RPO +84%、Azure +43%、供不应求）——这正是它和 Alphabet/Meta 那种"只增开支、需求存疑"的关键区别。市场愿意为"有订单支撑的扩张"付钱。

大白话：厂房不但没少盖，反而要盖得更猛——但这次手里多了 $678B 的预订单（RPO），等于"厂房还没盖完，租约已经签了一大堆"。所以市场不再担心"盖多了"，转而认为"盖得还不够快"。代价是：账面自由现金流要多熬一两年才能转正回升。

RPO（remaining performance obligations）是已经签约、但还没确认的收入——可以理解为"在手订单/backlog"。它 +84% 到 $678B，意味着未来几年的云收入已经有了合同锁定的强支撑。这就是为什么这一轮 $255–260B 的 capex，市场读成"有订单支撑的扩张"而非"盲目烧钱"。

05逻辑变了吗：从"太便宜"到"capex 能否赚回"

需要清醒的一点：我们买入逻辑里"估值太便宜"的那部分，已经基本兑现了。股价一周 +19%，forward P/E 从 ~20x 重估回 ~22–23x，回到它自己的历史区间。免费的重估午餐吃完了。

接下来的辩论转向：$255–260B/年的 capex，能不能赚回资金成本？ 好的一面是需求已被 RPO 证明；不确定的一面是——这么大的开支把 FCF 拐点推到了 ~FY2029+，中间市场会反复用"折旧压毛利、FCF 不回正"来质疑。从这里开始，你买的不再是"被错杀的便宜货"，而是"需求已验证、但现金流回报要多等一两年"的成长股。

更新后的评级：维持 BUY / OVERWEIGHT，目标价 $470 → $515

基本面更强，我们把 FY2027E non-GAAP EPS 上调到约 $20.5（原 $19.5，反映 Azure +45% 指引与 RPO 需求验证），给 ~25x 的基准倍数（需求已去风险，仍低于 28–32x 的历史区间）→ 目标价约 $515，仍比街共识 $557 低约 8%。相对现价 $465，剩余空间约 +11%。

立场：回调再加，不要追这根史诗大阳线

股价刚创下史上最大单日涨幅，此时追高本身就是一种"追涨"。更理性的做法是：在回调/盘整时分批加仓，而不是在情绪高点买入。风险回报已从盘前的"胖球"（+21%）收窄到"尚可"（~+11%）。若因 capex/FCF 的担忧出现回调（例如后续季度毛利继续压缩、FCF 迟迟不回正），反而是更好的加仓点，因为需求侧的逻辑已被 RPO 夯实。

06往后盯什么 · 风险

接下来的观察点：

  • Azure 增速能否维持 ~43–45%——需求温度计，供给（产能）能不能跟上是关键约束。
  • FY2027 capex 的实际兑现与口径——$255–260B 里 cash PP&E 与 finance lease 的拆分、以及那个"会计分类变更"的真实影响。
  • Gross margin——折旧洪峰下能否稳住（Q3 已到 67.6%）；这是 FCF 拐点前最容易被市场攻击的软肋。
  • Copilot 变现斜率——30M 席位之后的净增与 ARR 加速。
  • FCF 何时回正/回升——原本 FY2028，现在推后到 ~FY2029+；每季度的 OCF − capex 缺口是核心跟踪项。

主要风险

  • capex ROI（核心）：$255–260B/年若最终赚不回资金成本，FCF 长期承压、倍数回落。
  • 估值已重估：便宜的安全垫变薄；~$3.4T 的绝对市值下，Mag-7 轮动或利率冲击都可能盖过基本面。
  • OpenAI 关系：资本承诺、循环融资观感、以及让 GAAP EPS 失真（全年 +$0.67）。
  • 竞争：Alphabet（TPU/Gemini）、AWS、自研芯片对 Azure 增速/定价的长期压力。
